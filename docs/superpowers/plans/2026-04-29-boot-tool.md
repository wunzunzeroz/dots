# `boot` Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a personal CLI (`boot`) that fzf-picks a git worktree, then runs `<pm> install && <pm> start` with an auto-incremented Metro/Expo port. Lives in `~/dots/bin/`, symlinked onto `~/.local/bin/`.

**Architecture:** Single bash script. Functions for each concern (find repo root, list worktrees, pick via fzf with `$TMUX`-aware rendering, detect package manager from lockfile, find free port via `lsof`). Final step `exec`s the dev server so signal handling and exit codes behave like running `<pm> start` directly.

**Tech Stack:** bash 3.2+ (macOS default — no bash 4 features), `git worktree`, `fzf` / `fzf-tmux`, `lsof`. No package dependencies, no compilation.

**Spec:** `~/dots/docs/superpowers/specs/2026-04-29-boot-tool-design.md`

**Working directory:** All changes happen in `~/dots/`. The plan and the implementation are committed to that repo. No changes to `~/dev/sea-flux-frontend`.

## File Structure

| Path | Purpose |
|------|---------|
| `~/dots/bin/boot` (new) | Single executable bash script. All logic lives here. |
| `~/.local/bin/boot` (new) | Symlink to `~/dots/bin/boot`. Already on PATH. |

No additional config files, no companion scripts, no automated test files (spec defines manual test plan only).

### Function layout inside `boot`

| Function | Inputs | Output |
|----------|--------|--------|
| `die(msg)` | string | prints `boot: <msg>` to stderr, exits 1 |
| `find_repo_root()` | — | absolute path of repo root, or `die`s |
| `list_worktrees(root)` | repo root path | tab-separated `<path>\t<branch>` rows on stdout |
| `pick_worktree()` | rows on stdin | selected path on stdout, or empty + exit 0 on cancel |
| `detect_pm(dir)` | directory path | one of `yarn` / `pnpm` / `bun` / `npm`, or `die`s |
| `find_free_port(start)` | starting port | first free port in `[start, start+100]`, or `die`s |
| `main()` | — | orchestrates; final action is `exec` |

- [ ] **Step 3: Implement `list_worktrees`**

Add this function below `find_repo_root` in `~/dots/bin/boot`:

```bash
list_worktrees() {
  local path branch
  path=""
  branch=""
  while IFS= read -r line; do
    case "$line" in
      "worktree "*)
        # flush previous record before starting new
        if [ -n "$path" ]; then
          printf '%s\t%s\n' "$path" "${branch:-(detached)}"
        fi
        path="${line#worktree }"
        branch=""
        ;;
      "branch refs/heads/"*)
        branch="${line#branch refs/heads/}"
        ;;
      "detached")
        branch="(detached)"
        ;;
    esac
  done < <(git worktree list --porcelain)
  # flush last record
  if [ -n "$path" ]; then
    printf '%s\t%s\n' "$path" "${branch:-(detached)}"
  fi
}
```

Update `main()` to:

```bash
main() {
  find_repo_root >/dev/null
  list_worktrees
}
```

## Task 4: `pick_worktree` (fzf integration)

**Files:**
- Modify: `~/dots/bin/boot`

- [ ] **Step 1: Define the test**

2. Outside tmux (raw Terminal.app): picker fills the pane (plain `fzf`). Same select/cancel behavior.
3. With `fzf` removed from PATH: prints `boot: fzf not found. brew install fzf` to stderr and exits 1.

- [ ] **Step 2: Run baseline (should still print all rows non-interactively)**

Run: `cd ~/dev/sea-flux-frontend && boot`
Expected: tab-separated rows, no interactive picker.

- [ ] **Step 3: Implement `pick_worktree`**

Add this function:

```bash
pick_worktree() {
  command -v fzf >/dev/null || die "fzf not found. brew install fzf"
  local picker_cmd
  if [ -n "${TMUX:-}" ]; then
    picker_cmd=(fzf-tmux -p 80%,60% --with-nth=2,1 --delimiter='\t')
  else
    picker_cmd=(fzf --with-nth=2,1 --delimiter='\t')
  fi
  # fzf returns 130 on Ctrl-C/Esc; treat as silent success
  local selected
  if ! selected="$("${picker_cmd[@]}")"; then
    exit 0
  fi
  # First column is the path
  printf '%s\n' "${selected%%$'\t'*}"
}
```

Update `main()` to:

```bash
main() {
  find_repo_root >/dev/null
  local selected
  selected="$(list_worktrees | pick_worktree)"
  echo "selected: $selected"
}
```

Note: `--with-nth=2,1` shows the branch first then the path in the picker for readability, while the underlying delimiter-split row remains `path\tbranch`. The cancel path uses `exit 0` not `return` because we want the whole script to exit silently on cancel; `set -e` would otherwise propagate fzf's non-zero exit.

detect_pm() {
  local dir="$1"
  if [ -f "$dir/yarn.lock" ]; then

  elif [ -f "$dir/pnpm-lock.yaml" ]; then

  elif [ -f "$dir/bun.lockb" ]; then

}

## Task 6: `find_free_port`

**Files:**
- Modify: `~/dots/bin/boot`

- [ ] **Step 1: Define the test**

Three scenarios:
1. Nothing listening on 8081 → returns `8081`.
2. Something listening on 8081, nothing on 8082 → returns `8082`.
3. All ports 8081–8181 busy → exits 1 with `boot: no free port in 8081-8181`.

- [ ] **Step 2: Implement `find_free_port`**

Add this function:

```bash
find_free_port() {
  local start="${1:-8081}"
  local max=$((start + 100))
  local port="$start"
  while [ "$port" -lt "$max" ]; do
    if ! lsof -nP -iTCP:"$port" -sTCP:LISTEN >/dev/null 2>&1; then
      echo "$port"
      return 0
    fi
    port=$((port + 1))
  done
  die "no free port in $start-$((max - 1))"
}
```

`-nP` skips DNS/service-name resolution (fast, deterministic). `-sTCP:LISTEN` filters to listening sockets only so a previously-closed connection in TIME_WAIT doesn't make us skip a port.

- [ ] **Step 3: Verify scenario 1 (nothing on 8081)**

Make sure no `yarn start` is running anywhere, then:

Expected: `8081`

- [ ] **Step 4: Verify scenario 2 (something on 8081)**

- [ ] **Step 2: Replace `main` with the full implementation**

Replace the existing `main()` in `~/dots/bin/boot` with:

```bash
main() {
  find_repo_root >/dev/null
  local selected
  selected="$(list_worktrees | pick_worktree)"
  # Empty selection = user cancelled (pick_worktree already exit 0'd)
  [ -n "$selected" ] || exit 0

  cd "$selected"

  local pm port
  pm="$(detect_pm "$selected")"
  port="$(find_free_port 8081)"

  printf 'boot: using %s at %s on port %s\n' "$pm" "$selected" "$port"

  "$pm" install

  export RCT_METRO_PORT="$port"
  export EXPO_PACKAGER_PORT="$port"
  exec "$pm" start --port "$port"
}
```

The `printf` line is intentional and stays — it's the user-visible header showing what's about to run. No other comments in the script body.
